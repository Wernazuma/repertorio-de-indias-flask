Hgis de las Indias (Geodatabase)

Esta geodatabase es el producto clave de HGIS de las Indias.

Contiene numerosas feature classes y grupos de feature classes:

  • Capas adicionales Un grupo de feature classes que existe con independencia de la base de datos relacional. Incluye tanto capas de proveniencia ajena como productos de la investigación en el marco del proyecto.
  • Datos agregados Un grupo de feature classes productos de relacionar tablas con los lugares y territorios reconstruidos.
  • gz_info_1 Nombre para la capa principal para poblaciones. Agrega y combina información de diferentes tablas y aspectos calitativos.
  • Cabeceras Una feature class de aquellos lugares que eran cabeceras de entidades territoriales - partidos, jurisdicciones, provincias, obispados, audiencias...
  • Niveles territoriales (nivel_merge). Contienen objetos que representan la extensión de territorios de entidades territoriales, reconstruidos para diferentes niveles, en un determinado período. Existe una feature class para cada nivel territorial definido en HGIS de las Indias:
  • Partidos
  • Señoríos
  • Jurisdicciones
  • Provincias menores
  • Provincias
  • Provincias mayores
  • Intendencias
  • Superior Gobierno
  • Obispados
  • Arzobispados
  • Audiencias
  • Virreinatos

Feature classes artefactos del workflow y/o no relevantes para el usuario
