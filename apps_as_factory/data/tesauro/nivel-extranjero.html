Naciones extranjeras

HGIS de las Indias incorpora una capa que muestra también aquellos territorios que se encontraban o fuera del dominio español o dentro del dominio pero efectivamente colonizadas por otras naciones de 'tipo europeo'.

Cabe decir que fuera del dominio español no se distingue entre pretensiones y posesión efectiva ni se preocupa en detalle de pretensiones conflictivas entre varias naciones.

Las naciones en la base de datos son: *Portugal *Gran Bretaña *Francia *Haiti *Países bajos *Estados Unidos *Rusia *Dinamarca *Suecia *Neutral
