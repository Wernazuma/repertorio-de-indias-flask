The Geom (Geodatabase)

Esta geodatabase es el corazón geométrico de HGIS de las Indias. Contiene varias feature classes:

Feature classes base

  • a_gz_the_geom, puntos cuyas coordenadas representan las ubicaciones de los lugares del gazetteer. Se exporta a la base de datos relacional al principio del workflow para ser procesado y luego reimportado con información agregada como gz_info_1 y cabeceras.
  • LCG. Los polígonos que están en la base de las reconstrucciones territoriales, siguiendo el concepto_LCG. También sirve para establecer el partido y la provincia genéricos de los lugares del gazetteer.
  • Paises, una feature class con las naciones modernas para poder establecer el país genérico de los lugares del gazetteer.
  • Genericos_1 y Genericos_2 - productos de análisis espacial que agregan partido, provincia y país genérico a la feature class gz_info para crear gz_info_1 que luego se exporta a la geodatabase final: hgis_de_las_indias_gdb.
  • Capas adicionales Un grupo de feature classes que existe con independencia de la base de datos relacional. Incluye tanto capas tomadas de proveniencia ajeno como productos de la investigación en el marco del proyecto.
