Datasets and repositories

The project's raw data — Python code, the original relational tables, and the processed shapefiles — is deposited in public repositories:

  • Harvard Dataverse — the HGIS de las Indias data and code.
  • Yale Dataverse — mirror and repository for follow-up initiatives, including ARCA.
