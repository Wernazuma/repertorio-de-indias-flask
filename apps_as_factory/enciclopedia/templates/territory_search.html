Consejos de búsqueda

  • La búsqueda predeterminada coincide con palabras completas: "Cali" encuentra "Cali" pero no "Californias"
  • Use "OR" para buscar múltiples términos: "Costa Rica OR Costarrica OR Panama"
  • Use comodines (*): "Cali*" encuentra tanto "Cali" como "Californias" como "Alta California"
  • Active la Búsqueda Difusa para coincidencias aproximadas (encuentra variantes ortográficas pero puede incluir falsos positivos)

Search Tips

  • Default search matches complete words: "Cali" finds "Nueva Valencia" but not "Californias"
  • Use "OR" to search multiple terms: "Costa Rica OR Costarrica OR Panama"
  • Use wildcards (*): "Cali*" finds both "Cali", "Californias" and "Alta California"
  • Enable Fuzzy Search for approximate matching (finds spelling variants but may include false positives)
