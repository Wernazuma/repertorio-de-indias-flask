Consejos de búsqueda

  • La búsqueda opera con palabras completas: "Aro" encuentra "Aro" pero no "Arostegui"
  • Use "OR" para buscar múltiples términos: "González OR García"
  • Use comodines (*): "Gonz*" encuentra tanto "González" como "Gonzaga"
  • Active la Búsqueda Difusa para coincidencias aproximadas (encuentra variantes ortográficas pero puede incluir falsos positivos)

Search Tips

  • Default search matches complete words: "Aro" finds "Aro" but not "Arostegui"
  • Use "OR" to search multiple terms: "González OR García"
  • Use wildcards (*): "Gonz*" finds both "González" and "Gonzaga"
  • Enable Fuzzy Search for approximate matching (finds spelling variants but may include false positives)
