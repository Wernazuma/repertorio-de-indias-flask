The different flas apps (or blueprints in the factory version) serve several purposes:

encyclopedia: This app creates landing pages for places and territorial entities as well as people (administrators), pulling information on the chosen entity from a variety of tables.
orientation: simple app, giving potential collaborators an idea on whether/how/at which point to contribute and how to proceed.
transform: app transforming semi-aligned tabular data into a strict format.
matching: app that matches transformed data with the place or territory entities in the database, using automatic matching based on names and context, and disambiguation/manual matching for doubtful, ambiguous or unsolvable cases.
